# Rolling Dents Website

Canonical source for the Rolling Dents customer-facing website.

## Visual baseline

The frontend design and customer-facing layout are intentionally treated as the canonical visual baseline. Production hardening should preserve this presentation unless an explicit visual change has been approved.

## Hero asset

The approved landing-page hero is stored locally at `public/media/rolling-dents-hero-final.svg`. Desktop uses the image as a full-width hero background with the existing hero content overlaid; mobile retains the established responsive composition.
